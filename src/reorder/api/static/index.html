The data

3.4M real Instacart orders from 206k customers, stored in Postgres. Every feature is computed in SQL.

The models

LightGBM and a PyTorch GRU that reads the last 20 orders; the ensemble averages both. Test AUC 0.833.

The cut-off

Items above the dashed line clear the model's tuned threshold and go in the basket. The rest are less likely reorders.
